# 🔧 نظام إدارة مخزون قطع الغيار الذكي

## 🚀 طريقة التشغيل

1. **تحميل المشروع**: قم بنسخ جميع الملفات إلى مجلد على جهازك.
2. **التشغيل**: افتح ملف `index.html` مباشرة في المتصفح (Chrome/Edge/Firefox).
3. **لوحة المدير**: افتح `admin.html` لإضافة وإدارة القطع.

## 📁 الملفات الرئيسية

- `index.html` - واجهة المستخدم (البحث والعرض)
- `admin.html` - لوحة تحكم المدير
- `js/data.js` - قاعدة البيانات (JSON)
- `js/viewer3d.js` - عارض النماذج ثلاثية الأبعاد
- `models/` - ضع هنا ملفات الـ 3D بصيغة `.glb`

## 🎨 إضافة نماذج 3D

1. ضع ملفات `.glb` في مجلد `models/`
2. عدّل `js/data.js` وضع رابط الملف في حقل `model3d`
3. إذا لم يتوفر نموذج 3D، سيعرض النظام شكلاً بديلاً تلقائياً
